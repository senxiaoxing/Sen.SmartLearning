## 1. 设计原则

### 1.1 为什么需要图谱

没有图谱，这个 App 就只是"题库 + 宠物皮肤"。图谱提供三件事：

1. **自适应出题**：做错了知道该往哪个前置知识点退，做对了知道该往哪走
2. **诊断能力**：错误不是"错了"，而是"卡在凑十法的第二步"
3. **家长报告**：不报"做了 50 题"，报"进位加法已掌握，j/q/x 与 ü 相拼仍需练习"

### 1.2 ID 规范

**知识点 ID 使用语义 ID，不使用 UUID。**

```
M5.2   → Math,    第 5 单元, 第 2 个知识点
P2.4   → Pinyin,  第 2 单元, 第 4 个知识点
E4.3   → English, 第 4 单元, 第 3 个知识点
```

> ⚠️ **重要**：静态内容（知识点、题库）用语义 ID，用户数据（作答、掌握度）用 UUID。
> 原因：静态内容跨设备必须完全一致，否则备份导入时会错位；用户数据跨设备需要唯一性，否则合并时会撞车。这两类数据的 ID 策略**必须区分**。

### 1.3 知识点数据结构

```ts
interface KnowledgePoint {
  id: string                    // 'M5.2'
  subject: 'math' | 'pinyin' | 'english'
  unit: string                  // 'M5'
  unitName: string              // '20以内进位加法'
  name: string                  // '9加几'
  grade: '1A' | '1B'            // 一上 / 一下
  order: number                 // 全局教学顺序，用于线性推进
  prerequisites: string[]       // 前置知识点，如 ['M5.1', 'M3.3']
  itemTypes: ItemType[]         // 该知识点支持的题型
  difficulty: 1 | 2 | 3         // 基础难度
  isKeyNode: boolean            // ⭐ 是否关键节点（卡住会阻塞大量后续）
  misconceptions: string[]      // 典型错误类型，用于生成诊断性干扰项
  estimatedItems: number        // 达到掌握所需题量估算
}
```

### 1.4 掌握度状态机

```
locked ──前置全部 mastered──> available ──首次作答──> learning
                                                        │
                                    masteryScore ≥ 0.85 │ 且 consecutiveCorrect ≥ 5
                                                        ↓
                                                    mastered
                                                        │
                                              到达 dueAt │
                                                        ↓
                                                     review ──答错──> learning
```

- **locked**：前置未通关，不出题
- **available**：可以开始学，但还没做过
- **learning**：正在学，是出题主力
- **mastered**：已掌握，进入间隔重复队列
- **review**：到期待复习

## 3. 数学（Math）— 48 个知识点

> **M1~M9 是按知识主题聚类，不是教材目录单元号。**
> 教材把「数的认识」与「加减法」编在同一单元（如一上第一单元「5以内数的认识和加减法」），
> 而调度器需要它们各自成链才能做前置回退。与教材对齐的是**内容有无**和 `grade` 标记，
> 不是分组方式。

### M1 数感与计数（11 个）

| ID | 名称 | 前置 | 题型 | 难度 | 关键 |
|---|---|---|---|---|---|
| M1.1 | 数一数 1~10 | — | tap_count, choice_image | 1 | |
| M1.2 | 认识 0 | M1.1 | choice_image | 1 | |
| M1.3 | 数的顺序 1~10 | M1.1 | drag_order | 1 | |
| M1.4 | 基数与序数（第几个） | M1.3 | choice_image | 2 | |
| M1.5 | 比多少（同样多/多/少） | M1.1 | choice_image | 1 | |
| M1.6 | 比大小 > < = | M1.3, M1.5 | choice_text | 2 | |
| M1.7 | 数一数 11~20 | M1.1 | tap_count | 2 | |
| M1.8 | 20以内数的顺序与比大小 | M1.6, M1.7 | drag_order, choice_text | 2 | |
| M1.9 | 数的组成（十几 = 10 + 几） | M1.7 | input_number | 2 | ⭐ |
| M1.10 | 数位初步（个位·十位） | M1.9 | choice_image | 3 | |
| M1.11 | 10 加几和相应的减法 | M1.9 | input_number | 2 | |

> **M1.11 是凑十法的另一条腿。** 教材（一上第四单元「11~20的认识」）
> 把它排在数的组成之后，正因为 `9 + 5` 拆成 `10 + 4` 之后，
> 还得算得出 `10 + 4` 才算会凑十——只练 M3.3 的孩子会拆却答不出。
> 因此 M5.1 的前置挂的是 M1.11 而不是 M1.9（后者由 M1.11 传递）。
>
> 三档难度：`10 + 3`（正向）→ `13 - 3` / `13 - 10`（反向拆回）
> → `12 + 3` / `15 - 2`（不进位不退位，十位不动）。

**典型错误类型（misconceptions）**
- `count_skip` 数数跳数/重复数
- `ordinal_cardinal_confusion` 基数序数混淆（"第3个"选成"3个"）
- `symbol_reversed` 大于小于号方向反了 ⭐高频
- `order_reversed` 排序方向反了（要求从小到大却排成从大到小）
- `place_value_swap` 位值没建立起来 ⭐ —— M1.10 问十位答个位；
  M1.11 把 `10 + 3` 算成 4（10 的「1」被当成 1 个一）。
  两种表现同一种病，补救都是回小棒 / 十格阵，因此共用一个标签

> `order_reversed` 与 `count_skip` 是**两种病**，别混作一谈：
> 前者完全懂排序、只是没听清方向，补救是强调题干里的「从小到大」；
> 后者是数序本身不熟，得回去练数数。由 `drag_order` 题型产出。

### M5 20以内进位加法（5 个）

| ID | 名称 | 前置 | 题型 | 难度 | 关键 |
|---|---|---|---|---|---|
| M5.1 | **凑十法原理** | M3.3, M1.11 | drag_combine | 2 | ⭐⭐ |
| M5.2 | 9 加几 | M5.1 | input_number | 2 | |
| M5.3 | 8、7、6 加几 | M5.2 | input_number | 3 | |
| M5.4 | 5、4、3、2 加几 | M5.3 | input_number | 3 | |
| M5.5 | 20以内进位加法综合 | M5.4 | input_number | 3 | |

**misconceptions（干扰项必须按这些生成）** ⭐
- `no_carry` 忘记进位 → `9 + 5` 答 `14`✓ 错答 `13`（当成 9+4）
- `carry_lost` 凑十后忘记加剩余 → 答 `10`
- `digit_concat` 直接拼接 → 答 `95`
- `sub_instead` 做成减法 → 答 `4`
- `ten_split_wrong` ⭐ 知道要拆但**补数算错**（把 5 拆成 2 和 3 去补 9）

> `ten_split_wrong` 由 `drag_combine` 题型产出，是它相对填空版的独有价值：
> 它把「进位规则不熟」和「**10 的分与合没打牢**」区分开了。
> 命中它意味着问题在地基，补救路径是**回退 M3.3**，而不是继续练 9 加几。
> 破十法（M6.1）共用这个标签，含义对称（不知道要先拆出一个 10）。

> **这是"智慧"最直接的落点**：孩子选了 `13` 说明凑十过程丢了 1，选了 `10` 说明凑十后忘记加。
> 两种错误对应完全不同的补救路径。**随机干扰项永远给不了这个信息。**

### P3 拼读规则（4 个）⭐ 拼音的核心难点全在这

| ID | 名称 | 前置 | 题型 | 难度 | 关键 |
|---|---|---|---|---|---|
| P3.1 | 两拼音节（声母+韵母） | P2.1, P1.3 | drag_combine | 2 | ⭐ |
| P3.2 | 三拼音节（声+介+韵） | P3.1 | drag_combine | 3 | ⭐⭐ |

| P3.4 | 声调标注规则 | P1.3, P4.1 | choice_text | 3 | ⭐ |

**P3.4 规则**：有 a 找 a，没 a 找 o e，i u 并列标在后。

**misconceptions**
- `u_umlaut_kept` jü 而不是 ju ⭐最高频错误
- `tone_wrong_position` 声调标错位置（如 `xiào` 标成 `xiaò`）
- `tone_confusion` **听**不出是第几声（把 `wú` 听成 `wǔ`）
- `three_syllable_missing_medial` 三拼音节漏掉介母

> `tone_confusion` 与 `tone_wrong_position` 是两回事：前者是**听**的问题
> （压根没听出几声），后者是**写**的问题（知道几声但标错地方）。
> 补救路径不同——前者回去练四声，后者练标调规则。
> P1.3 的听音题产出前者。

## 5. 英语（English）— 30 个知识点

> **不绑教材。** 一年级英语各地教材不统一（PEP 三年级起点 / 新起点 / 外研社 / 牛津上海版），
> 且课标只要求**听说、不要求读写**。因此做通用启蒙，全部题型零阅读门槛。
> 词汇总量 **158 词/句/字母**。

### ⭐ 为什么字母排在最前

课标路径是「听说优先」，字母通常放到一下才系统教，本图谱原先也照此排：
问候语 → 数字 → … → 字母（标 1B）。**但那个顺序对零基础自学不成立**：

| | 问候语打头 | 字母打头 |
|---|---|---|
| 孩子说得清「学到哪了」吗 | ❌ 没有边界 | ✅ 26 个，亮了几个一眼看得见 |
| 有没有可玩的载体 | 场景 emoji（🙋 表示「你好」）很勉强 | 字母卡收集墙，翻一张听一句 |
| 后面的词汇接得上吗 | 无关 | ✅ A is for **apple**，首字母单词先见一面 |

所以改成字母打头 + 字母卡收集墙（`features/english/LetterWall.tsx`），
紧跟具体名词（动物 → 食物 → 颜色 → 数字），抽象的问候语与句型排到最后。

> ⚠️ **顺序由 `order` 决定，不是由前置依赖决定。**
> 字母与词汇是并行的两条线——学 cat 不必先学完 26 个字母，
> 所以动物、颜色这些单元一律**无前置**。设成依赖字母会变成
> 「字母没学完就锁死一切」，那是另一回事。

### E1 字母（9 个）⭐ 零基础的起点

| ID | 名称 | 内容 | 前置 | 难度 |
|---|---|---|---|---|
| E1.1 | Aa–Ee | 5 个字母 | — | 1 |
| E1.2 | Ff–Jj | 5 个字母 | E1.1 | 1 |
| E1.3 | Kk–Oo | 5 个字母 | E1.2 | 1 |
| E1.4 | Pp–Tt | 5 个字母 | E1.3 | 1 |
| E1.5 | Uu–Zz | 6 个字母 | E1.4 | 1 |
| E1.6 | 大小写配对 | — | E1.5 | 2 |
| E1.7 | 字母歌 | ABC song | E1.1 | 1 |
| E1.8 | 听音辨字母 | 候选池是整张字母表 | E1.5 | 3 |
| E1.9 | 首字母对应单词 | A-apple, B-bird… | E1.5 | 2 |

**⭐ 朗读的是整句「A is for apple.」，不是孤立的字母。**
孤立的 `A` 有歧义——既是字母名 /eɪ/ 也是冠词 /ə/，TTS 挑哪个不由我们决定，
而**发音教错比没有声音严重得多**。整句里那个 A 只可能是字母名，
而且字母与首字母单词一次带出，正是字母教学的标准句式。

> 代价：E1.8「听音辨字母」因此变成**听整句选字母**，
> 孩子既能靠字母名也能靠单词认出来。这不是损失——
> 它把 E1.9 的考法吸收了进来，两者的差别改由候选池宽度体现。

**misconceptions（英语通用）**
- `similar_sound` 音近词混淆（cat/cake、bear/pear、pen/ten）⭐高频，也是兜底标签
- `letter_mirror` 字母 b/d、p/q 镜像混淆

  它是 E5.2 真正要考的东西：干扰项**必须**把对应的个位数摆进选项，

  （原定义为「13/30 类混淆」，但 30 属于阶段 2 内容，一上学不到，
  实际落点是 teen 与个位数的对立。）

## 6. 摸底测评（Placement Assessment）

首次启动时进行，**5 分钟内完成**，用于定位起点，避免"上过衔接班的孩子被简单题劝退"。

### 抽题策略

只测每个单元的**代表性知识点**（`isKeyNode` 或单元末位），共 **18 题**：

| 科目 | 探测点 | 题数 |
|---|---|---|
| 数学 | M1.6, M3.3, M4.5, M4.6, M5.2, M5.5, M6.2, M7.3 | 8 |
| 拼音 | P1.3, P2.4, P3.1, P4.1, P5.3, P6.1 | 6 |
| 英语 | E1.1, E2.1, E3.1, E5.1 | 4 |

### 二分定位逻辑

```
对某个单元：
  代表题答对 → 该单元前序知识点全部标记 mastered（masteryScore = 0.85 起评）
  代表题答错 → 向前回溯一层，追加 1 题探测
  连续 2 题答错 → 该单元及之后全部保持 available/locked，从单元首个知识点开始
```

**测评本身要游戏化包装**：不叫"测试"，叫「和宠物一起去探险，看看能走多远」。答错不给红叉，只说"这里有点难，我们回头再来"。**绝不能让第一次体验就产生挫败感。**
