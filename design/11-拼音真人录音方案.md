## 0. 问题：声母 f 读成了「佛」

拼音墙上声母 f 的卡片：屏幕上写 `f`，耳朵里听到的是饱满的 **fó**。

比「听起来别扭」严重得多——**孩子听到的不是声母，而是一个完整音节**。实测数据：

| | 人声段 | 其中**强能量（元音）** | 元音占比 | 相对底噪 |
|---|---|---|---|---|
| 现有 `pinyin.fo2.mp3`（TTS 念「佛」） | 0.37s | **0.31s** | **84%** | −91 dB |
| 真人录音 `f.mp3`（候选素材） | 0.74s | **0.06s** | **8%** | −58 dB |

能量包络（每格 30ms，数字为相对峰值）：

```
现有 pinyin.fo2（TTS）
  ...........000009988999655410...........................
  └─ 长静音 ─┘└─ 一个饱满的元音峰 ─┘└─── 长静音 ───┘

真人 f.mp3
  ......085212493445567777776643210......
  └─ 连续摩擦噪声，没有元音平台 ─┘
```

`pinyin.fo2` 的 0.37s 人声里 84% 是元音，**摩擦成分几乎为零**——从头到尾就是 `ó`。
底噪 −91 dB ≈ 数字静音，是 TTS 合成；−58 dB 是录音环境噪声，是真人。

## 1. 为什么换载体字治不了本

**根因有两层，第二层才是要害。**

**第一层：声母大多不能独立成音。** `b p d t g k j q zh ch z c` 这些塞音、塞擦音孤立发声只有几十毫秒爆破，人耳听不见——这正是《汉语拼音方案》要用「呼读音」（b 玻、f 佛）的原因。项目照教材选字，**并没有选错字**。

**第二层：教材示范是「轻短」，TTS 念的是「饱满」。** 人教版教案原文：

> 听广播的「播」读得**轻短些**，发音时，把两片唇闭合，把气憋住，然后突然放开，让气流冲出双唇就是「b」的音，读得轻……

教材要的是**又轻又短的呼读音**（擦音 f/s/sh/x/h 更接近纯辅音）。而 Edge TTS 念「佛」必然读出完整的 `fó`——元音饱满、声调鲜明、时长完整。

**换成「夫 fū」还是有一声 + 元音，换任何字都一样。** 病灶不在选字，在「TTS 念字」这个范式。

**核心矛盾：授权干净的开源素材全都只有「音节」；有「声母本音」的 cmguo 恰恰没有授权。**

这不是没找全，而是结构性的——音节是语言学习素材（外国人学中文），声母本音是**小学教学**素材，后者基本是商业教材/点读产品的资产，不会以开源协议放出。

### 2.2 权威素材存在但受限

人教社/国家中小学智慧教育平台的一年级配套音频最专业，但**有版权**，不能进公开仓库。

### 2.3 已决策的边界（用户拍板）

- 采用 cmguo 的素材，**保留在 git 仓库里**
- 用户**手动把 GitHub 仓库改成 private**，版权风险由用户承担
- 接受真人录音进 `dist/` 并被 `npm run deploy` 推上 gh-pages
- **不采用**家长人工录音（不专业）；**不考虑**换 TTS 引擎（会牵动全项目的音频链）

## 3. 方案设计

### 3.1 ⭐⭐ 为什么不就地覆盖 118 条，而要新增 47 条 key

`pinyin.fo2`（声母 f 的呼读音）**同时被题目当作「一个音节」使用**：

| 位置 | 用法 |
|---|---|
| `itemTemplates.ts:498` | P2.1 `listen(...INITIALS.filter(['bo','po','mo','fo']))` |
| `itemTemplates.ts:502-507` | P2.3~P2.6 同样直接以声母呼读音为目标音节 |
| `itemTemplates.ts:592` | P8.1 `listen('P8.1', USABLE_SYLLABLES)` — 含全部 23 条 |
| `itemTemplates.ts:595-599` | P8.3 听音选字，19 条声母会是目标（播 `fo2` 选「佛」） |
| `itemTemplates.ts:568` | P7.1 `odd(...byBase([...'bo'...]))` |

这些题的选项是**带调拼音**（`pinyinListen.ts:53-54` 用 `displayForm(target)`，对 INITIALS 得到 `bō/pō/mō/fó`），题干音频也是同一个 key（`:69`）。

**若就地换成纯 /f/**：P8.3「听 /f/ 选『佛』」无解、P4.4「听 /f/ 选韵母 o」选项与音频矛盾、P2.7 彻底错位、P7.1 选项写 `bō` 却播 `/p/`。

而**拼音墙**的声母卡（`pinyinChart.ts:145-173`）`card('f','一根拐棍','fo',2)`：
- `form: 'f'` → 屏幕显示**字母 f**
- `clipKey: 'pinyin.fo2'` → 播「佛」

**屏幕上写 `f`、耳朵里听到「佛」——这才是用户抱怨的那一处。**

→ **结论**：118 条现有 key 语义不变（只换音源），另加 **47 条 `pinyinbare.*`** 给拼音墙 + 答案语音。

两条轨道是**刻意的**，不是冗余：

```
拼音墙（教的地方）   声母卡显示 f   → 播 pinyinbare.f   纯 /f/       ✅ 本音
题目（练的地方）     选项显示 fó    → 播 pinyin.fo2     呼读音 fó    ✅ 一致
```

### 3.2 映射规则

| 目标文件 | 来源（cmguo 同名文件） | 条数 |
|---|---|---|
| `pinyin.<base><tone>.mp3` | `<base><tone>.mp3` | 118 |
| `pinyinbare.<letter>.mp3` | `<letter>.mp3`（无调本音） | 47 |

`pinyinbare.*` 的 47 条来源：

- **声母 23**：`INITIALS` 的 `initialOf(s.base)` → `b p m f d t n l g k h j q x zh ch sh r z c s y w`
- **韵母 24**：`SINGLE_FINALS`(6) + `COMPOUND_FINALS`(18) 的 `base`（`ü`→`v`）→ `a o e i u v ai ei ui ao ou iu ie ve er an en in un vn ang eng ing ong`

已实测（对照 GitHub tree 的 sha）：118 个 `<base><tone>.mp3` **零缺失**；47 个无调文件**全部存在**。

> ⭐ `pinyinbare.ong` 顺带解决了 design/07 §3.3 里「`ōng` 没有干净载体、只能借例词『松』」这个死角。
> ⭐ `pinyinbare.vn`（ün）解决了「载体字『韵』是四声、而韵母不教声调」的不一致。
> ⚠️ `pinyinbare.*` 共 47 条**不管拼音墙上展示多少张卡**都全量生成——数据完整，将来加卡不用补音频。

### 3.3 使用点只有两处

- `src/data/seed/pinyinChart.ts` — 声母(23) + 单韵母(6) + 复韵母(9) + 鼻韵母(5) 这些卡的 `clipKey` 改指 `pinyinbare.*`；整体认读(16) 与声调卡保持 `pinyin.*`（它们的 form 是音节本身，如 `zhi` 念 `zhī` 是有意的）
- `src/domain/pinyinCallName.ts:32-85` — 声母段与韵母段改指 `pinyinbare.*`。「答案是 g」由「哥」变成**轻短本音**，与人教版「读得轻短些」一致

### ⚠️ 有两处**注定不会完美**，先说在前面

**其一：塞音的本音发不出来。** `b d g p t k` 孤立发声只有几十毫秒爆破，
人耳根本听不见——这正是《汉语拼音方案》要用呼读音的原因。
素材录的是它们的**轻短版**（实测 `b.mp3` 人声段 0.48s、含元音成分）。
听起来如果「还是个音节」，那是素材质量的天花板，不是接线错了。

**其二：运行时裁静音的门限没跟着调过。**

```
src/platform/speechClips.ts   SPEECH_THRESHOLD = 0.03（相对该片段峰值）
                              MARGIN = 0.03（前后各留 30ms）
```

这两个值是按「合成音底噪近乎为零」调的（design/07 §2.3）。
真人录音底噪 −58 dB，远低于 3% 门限，能量法成立；
但**擦音起音比 TTS 慢**，30ms 余量有削掉字头的风险。
真出现「f 的摩擦段被吃掉」，**只调拼音这一档**，别全局改。

### 发现问题的处置

1. 单条读不准 → 上游素材就那样，换不了字（没有载体了），只能记下来
2. 想换整批 → 改 `fetch-pinyin-voice.mjs` 的 `COMMIT` 或换上游仓库，跑 `npm run pinyin:voice -- --force`
3. 摩擦音被裁 → 调 `speechClips.ts` 的 `MARGIN`（只对拼音生效需另加分支）
